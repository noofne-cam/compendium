> A map from a collection $(A_i)^n$ to a set $B$; 
> in such a case called $n$-ary.
> 
> To be interpreted as a *way* in which elements from some sets *combine* to form another element. Usually, $A_i \subset B$ and we seek *closure*, $B \subset A_i$ with all $A_i$. In many cases as well the $A_i$ are all the same. 

---
**Properties**
- *Commutativity:* If the domain sets are equal, and the image is independent of the order of the operands. 
- *Associativity:* If the compound application of the operation on several elements is well-defined and is independent of the order of computation.
- *Identity:* (of binary operations) If the image set equals one of the domain sets, and the other contains an element such that the operation of that element with any element from the domain-image set results in the same element.
- *Inverse:* (of binary operations) If the *(cf. Id.)* identity exists, the two domain sets are equal, *such that* they both possess the same identity, and for each element there exists an element such that their result under the operation is the identity.
